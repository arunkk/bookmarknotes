          Saving stars and notes

          Stars and notes are written straight back to this repository as commits, so they follow you to any browser. That needs a GitHub token with permission to change this one repo. Without it, everything here stays readable but nothing can be edited.

          Kept in this browser only and sent only to api.github.com. Create one at github.com/settings/personal-access-tokens. Anything you write here is public, because the repository is public.
